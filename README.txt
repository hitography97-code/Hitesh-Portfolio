Hitesh Choudhary — Portfolio

A modern, responsive personal portfolio website for **Hitesh Choudhary**, showcasing development, data, photography, and videography work.

✨ Features

- Modern dark portfolio design
- Cyan / purple gradient accents
- Responsive desktop and mobile layout
- Animated background and profile orbit
- About Me section
- Technical Skills section
- Projects section
- Contact section
- Working email contact form
- GitHub, LinkedIn and Instagram links
- Resume button
- GitHub Pages ready

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python `http.server`
- SQLite database
- Google Fonts

🚀 Run the Backend

1. Open PowerShell in this folder.
2. Run `python server.py`.

Contact form submissions are stored in `portfolio.db`. You can view saved
messages through the `/api/messages` endpoint while the server is running.
